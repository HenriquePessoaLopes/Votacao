Como funciona

  1. Cadastre os associados que poderão votar. Ir para Associados
  2. Crie a pauta que será votada. Ir para Pautas
  3. Abra uma sessão de votação com duração em minutos. Ir para Sessões
  4. Cada associado registra o seu voto (um por pauta). Ir para Votação
  5. Depois que a sessão encerrar, consulte o resultado. Ir para Resultados
